# 운영 계획 (PLAN)

세미툰 라이프 제작을 어떻게 나눠서 굴리는지 적는 문서입니다. 진행 상황과 결정은 여기에 계속 갱신합니다.

## 역할
| 역할 | 누가 | 맡는 일 | 결과물 |
|---|---|---|---|
| 오너 | 이유정 | 최종 결정, 현업 감수(이벤트 문장·직업 묘사), 머지 | 결정 기록 |
| 운영 + 로직 | Claude | 일정·역할 조율, 규격(SPEC) 관리, 문서 통합·검토, 게임 코드 | PLAN, SPEC, `life/js/` |
| 시스템 설계 | Claude 서브에이전트 | 생애 흐름, 교육·커리어, 관계, 건강, 성향, 갈림길, 엔딩·되돌아보기 | `SYSTEMS.md`, `companies/jobs/character.json` |
| 경제 설계·고증 | Claude 서브에이전트 | 연봉·물가·집값·금리·주가 역사, 주식·부동산·대출 규칙 | `ECONOMY.md`, `economy_history.json` |
| 업계 역사 고증 | Claude 서브에이전트 | 1947~2026 반도체 시황 | `market_history.json`, `MARKET_HISTORY.md` |
| 미래 고증 | Claude 서브에이전트 4명 | 2026~2060 공정·메모리, 새 컴퓨팅, 시장·사회, AI·자동화 전망 (논문·리포트·기사) | `FUTURE.md`, `future_tech.json` |
| 이벤트 작가 | Claude 서브에이전트 | 생애 단계별 사건 문장 대량 작성 | `data/events/*.json` |
| 검토 | Claude 서브에이전트 | 규격 일관성, 재미, 밸런스, 법적 위험 점검 | 검토 의견 → PLAN |
| 디자인 | GPT | 화면, 캐릭터·아이콘, 연출 | `life/css/`, `life/assets/`, `life/js/fx.js`, `DESIGN_BRIEF.md` |
| 콘텐츠·교차 검토 | GPT | 직업별 사건, 업적·칭호, 이름, 일반 뉴스, 직업 확장, 되돌아보기 문구, 미래 사건, 데이터·기획 검토 | 지시서 `life/tasks/gpt/T01~T10` |

서브에이전트 결과는 운영(Claude)이 검토하고 통합한 뒤 PR로 올립니다. 분량이 많은 콘텐츠와 교차 검토는 크레딧을 나누기 위해 GPT가 맡고, 오너가 `life/tasks/gpt/`의 지시서를 GPT에게 전달합니다. 서로 요청은 `life/docs/REQUESTS.md`에 적습니다.

## 단계
| 단계 | 내용 | 끝나는 조건 | 상태 |
|---|---|---|---|
| 1. 기획 | 규격, 시스템, 경제, 시황, 이벤트 1차(약 120개) | 문서·데이터가 SPEC과 맞고 검토 통과 | 진행 중 |
| 2. 프로토타입 | 캐릭터 만들기 → 1년 루프 → 사건 → 죽음 → 되돌아보기. 기본 디자인 | 한 인생을 처음부터 끝까지 플레이 가능 | 대기 |
| 3. 콘텐츠 확장 | 이벤트 300~500개, 업적·칭호, 회사 운명 연출 | 1940·1970·2000년생으로 각각 돌려 봐도 다른 삶 | 대기 |
| 4. 디자인 | GPT가 화면·그림·연출 입힘, 되돌아보기 공유 이미지 | 모바일 390px에서 깔끔 | 대기 |
| 5. 출시 | 밸런스 시뮬, 법률 확인, 공개 | 오너 승인 | 대기 |
