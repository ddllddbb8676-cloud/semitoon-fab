# 이벤트 작성 가이드

이벤트는 코드가 아니라 `life/data/events/*.json` 데이터로 만듭니다. 오너나 누구든 문장만 써서 추가할 수 있게 하는 게 목표입니다.

## 형식

```json
{
  "id": "teamlead_today",
  "age": [25, 60],
  "year": [1974, null],
  "when": { "job_group": "현장" },
  "market": null,
  "weight": 3,
  "once": false,
  "text": "팀장님이 다가와 물어요. \"오늘 되지?\"",
  "choices": [
    { "label": "된다고 한다", "effects": { "mental": -5, "reputation": 3, "trait.work_life": 5 }, "result": "밤 11시에 됐어요. 팀장님은 이미 퇴근했고요." },
    { "label": "솔직히 내일이라고 한다", "effects": { "reputation": -1, "trait.conform": -5, "title_progress": "소신 엔지니어" }, "result": "팀장님 표정이 굳었지만, 다음 날 정말로 됐어요." }
  ],
  "default": 0
}
```

| 필드 | 뜻 |
|---|---|
| `age` | 뜰 수 있는 나이 범위 |
| `year` | 뜰 수 있는 연도 범위 (`null`은 제한 없음) |
| `when` | 조건. `job_group`, `job`, `sector`, `region`, `stat_min`, `wealth_min`, `has` (가족·물건) 등 |
| `market` | 시황 조건. 예: `{ "memory": [1, 2] }`면 메모리 호황일 때만 |
| `weight` | 같은 해 후보 중 뽑힐 확률 가중치 |
| `once` | 한 인생에 한 번만 |
| `choices` | 선택지 2~4개. `effects`는 능력치·돈·경력·관계 변화, `result`는 결과 문장 |
| `default` | 시간 안에 안 고르면 자동으로 고를 선택지 |

문장 규칙: 부드러운 존댓말(해요체), 짧게, 장면이 보이게, 현업 용어는 그대로. 선택지 이름은 짧은 행동형("된다고 한다"). 아래 예시는 요약이라 말투가 다를 수 있습니다. 키 이름은 `SPEC.md`를 따릅니다. 실제 회사를 알아볼 수 있는 이름에 산재·비리 같은 부정적 사건을 고정으로 붙이지 않습니다 (회사는 `{company}` 자리표시로 판마다 랜덤).

## 예시 (생애 단계별)

### 유아·어린이 (1~12세)
- **아빠의 방진복 사진** (부모가 `semi`) — "아빠 회사 사진에 하얀 우주복을 입은 사람들이 있다." → [나도 우주인 될래] 꿈: 엔지니어 / [무서워] 아무 일 없음
- **과학 상자** (8~12세, 손재주 50↑) — "생일 선물로 과학 상자를 받았다." → [밤새 조립] 손재주 +5 / [게임기로 바꿔 달라고 조른다] 사교성 +2, 손재주 -2
- **공장 앞 동네** (출생 지역 `fab_since` ≤ 올해) — "동네에 엄청 큰 공장이 들어온다. 밤에도 불이 꺼지지 않는다." → 반도체 접점 기록 "어린 시절 공장 불빛"

### 학생 (13~19세)
- **진로 상담** — "선생님이 묻는다. 뭐가 되고 싶니?" → [반도체 공학] / [마이스터고] / [아직 모르겠어요]
- **반도체 마이스터고 설명회** (2010년 이후, 손재주 55↑) — "졸업하면 바로 대기업 오퍼레이터래." → [지원한다] / [인문계 간다]

### 청년 (20~34세)
- **첫 지원서** (시황 연동) — 호황이면 "공채 규모 역대 최대" 문구, 불황이면 "올해 채용 없음" 문구가 뜸
- **팹 건설 알바** (대학생, 체력 55↑) — "방학 동안 평택 팹 건설 현장 일당 18만 원." → [간다] 체력 -5, 돈 +, 접점 기록 / [안 간다]
- **경쟁사 스카우트** (재직 3년↑) — "{rival}에서 연봉 1.5배를 제안했다. 대신 근무지가 {region}이다." → [이직] / [남는다] / [제안서로 연봉 협상] 사교성 체크
- **첫 야간 교대** (`shift`) — "새벽 3시, 라인 알람이 울린다." → [달려간다] 멘탈 -3, 경력 +2 / [선배를 깨운다] 사교성 체크

### 중년 (35~59세)
- **성과급 날** (재직 회사 실적 +2) — "성과급이 연봉의 50%다. 단톡방이 난리다." → [집 대출 갚기] / [반도체주 몰빵] / [가족 여행]
- **구조조정 명단** (재직 회사 실적 -2) — "희망퇴직 신청을 받는다는 공지가 떴다." → [버틴다] 멘탈 체크 / [위로금 받고 나간다] 돈 +, 무직
- **우리 회사가 인수됐다** (회사 이벤트) — "내일부터 사원증 로고가 {acquirer}로 바뀐다."
- **원청이 망했다** (협력사 직군) — "{company} 공장이 멈췄다. 식당도 다음 달까지만 운영한다."

### 노년 (60세~)
- **경비원으로 다시 반도체** (아직 접점 없음, 60~70세) — "{company} 공장 경비 모집. 집에서 가깝다." → 접점 보장 장치
- **손주의 질문** (자녀가 반도체 직군) — "할머니/할아버지, 엄마 회사는 뭐 만들어?" → 되돌아보기 연출로 이어짐

## 인생에 남는 사건만 (v0.3)

“인생에 영향 없는 소소한 질문은 빼자”는 오너 결정에 따라, 사건마다 **인생에 미치는 영향**을 데이터에서 점수 매겨 소소한 사건은 끕니다. 지우지 않고 `life/data/event_curation.json`의 `disabled`에 올리면 엔진이 그 id를 읽지 않아요. 목록은 `node life/tools/curate.mjs`가 다시 만듭니다.

- **영향 규칙** (선택지마다 계산, 사건 점수 = 가장 큰 선택지): 높음 = 인생을 바꾸는 `do`(job·partner·child·house·invest·coin·loan·move·school·military)·`later`·돈 0.3배 연봉↑ / 보통 = 그 밖의 `do`·돈 0.05배↑·능력치 ±5·성향 ±15·행복·친구 ±8·평판 ±5·다른 사건이 `when`으로 읽는 플래그 / 낮음 = `semi`만, 작은 수치.
- **끄는 조건**: 점수가 낮음 이하 + `major`·`drama`·`milestones` 파일이 아님 + `trigger` 없음. 켜진 사건이 `later`·`goto`로 부르는 사건은 켜 둡니다.
- **손으로 살리기**: 숫자는 작아도 기억에 남는 장면(돌잡이 메모리 칩, 공장 불빛, 첫 방진복, 손주의 “반도체가 뭐예요?”)은 `curate.mjs`의 `RESCUE`에 이유와 함께 넣습니다.
- **새 사건을 쓸 때**: 선택지 하나는 꼭 인생에 흔적을 남기게(돈·관계·직장·집·건강·`later`). 장면만 좋고 효과가 작으면 꺼집니다.
- **큰 고비 사건**은 `events/milestones.json` (이혼·사별·간병·난임·입시·전세·연금 같은 보편적인 전환점). 여기와 `major`·`drama`는 늘 켜져 있어요.
- **속도**: 소소한 사건이 빠진 만큼 추첨 자리마다 “아무 일 없음”이 끼어듭니다 (`events.js`의 `QUIET_W`, 생애 단계별). 그래서 `weight`가 실제 확률처럼 작동해요 — 슬픈 사건(친구의 죽음·부모 이혼·보이스피싱)은 0.2~0.6, 흔한 고비(조부모와의 이별·버킷리스트)는 2~3. 확인: `node life/tools/life_sim.mjs 1000 --ms` (인생당 사건 40~60개, 단계마다 큰 줄기 사건 2개↑).

## 반도체 접점 기록

반도체와 닿은 순간은 `semi_moments`로 따로 기록해 되돌아보기의 "내 인생의 반도체 순간" 카드에 씁니다. 예: 어린 시절 공장 불빛, 첫 출근, 첫 성과급, 구조조정, 경쟁사 이직, 퇴직 후 경비원.
