# 사건 문장 작성 가이드

세미툰 라이프의 사건 문장은 **"아, 이거 우리 팀 얘기네"** 하고 웃게 만드는 게 목표입니다. 형식(`SPEC.md`, `EVENTS.md`)이 맞아도 문장이 밋밋하면 실패예요. 모든 문장 작업(T01, T07, T09, T12, T13)은 이 가이드를 먼저 읽습니다.

## 좋은 예와 아쉬운 예
| | 문장 |
|---|---|
| 좋음 | 체험 학습으로 반도체 홍보관에 갔어요. 방진복을 입고 에어샤워에 들어가니 앞머리가 하늘로 섰어요. |
| 좋음 | 아침 7시 반, 출근 러시예요. 텀블러와 노트북과 우산이 줄줄이 검색대를 지나가요. |
| 좋음 | (결과) "교대근무 힘들어요?" 답글이 달렸어요. "적응됩니다(아님)" |
| 아쉬움 | 동료가 펜 잠깐 빌릴 수 있을까요 하고 물어요. → 어느 직업이든 똑같고, 고민할 게 없어요. |
| 아쉬움 | (결과) 서두름과 생략을 같은 말로 쓰지 않았어요. → 교훈만 있고 장면이 없어요. |
| 아쉬움 | 퇴근 후 가족이 음악 틀어도 될까요 하고 물어요. (타워크레인 기사) → 그 직업과 상관이 없어요. |

## 규칙
1. **첫 문장에 장면 하나**: 장소·시간·물건 중 하나는 꼭 (클린룸, 새벽 3시, 방진복, FOUP, 알람 소리, 식판, 검색대, 크레인 운전석).
2. **그 직업이어야 겪는 일**: 직업 사건은 다른 직업 이름으로 바꿔 넣어도 말이 되면 다시 씁니다.
3. **선택지는 진짜 고민**: 무언가를 얻으면 무언가를 잃게 (평판 vs 멘탈, 돈 vs 가족, 안전 vs 속도). 두 선택지 효과가 비슷하면 안 됩니다.
4. **결과는 장면으로 끝내기**: 교훈·다짐으로 끝내지 않습니다. 3개 중 1개쯤은 작은 반전이나 웃음 (괄호 속 속마음, 구체적 숫자, 의성어).
5. **현업 말 그대로**: Lot, 웨이퍼, 레시피, 인터락, 알람, PM, 셋업, 홀드, 스크랩, 수율, 반장, 4조 3교대, 원청·협력사. 틀리게 쓸 바엔 안 씁니다.
6. **존댓말 해요체, 짧게**: 한 문장 40자 안팎, 사건 본문 두 문장 이내.
7. **하지 않을 것**: 실제 회사·사람 이름, 회사 내부 수치(실제 공정 조건·수율), 사고·해고·질병·전쟁을 웃음거리로, "~하지 않아요"로 끝나는 교훈 반복.

## 묘비명·인생 요약
- 한 줄 위트 + 품위. 그 사람의 직업·성향이 보이게.
- 좋음: "마지막 알람은 끄지 못했지만, 라인은 멈추지 않았어요." / "평생 남의 방진복을 빨았지만, 제일 깨끗한 건 그의 이름이었어요."
- 아쉬움: "약속한 시간과 순서를 지키는 데서 마음이 놓였어요." → 누구에게나 맞는 말이에요.

## 스스로 점검
- [ ] 이 사건을 다른 직업 이름으로 바꾸면 어색한가? (어색해야 좋음)
- [ ] 선택지마다 얻는 것과 잃는 것이 다른가?
- [ ] 결과 문장이 장면으로 끝나는가?
- [ ] 현업 사람이 읽고 "맞아" 할 디테일이 하나 이상 있는가?
