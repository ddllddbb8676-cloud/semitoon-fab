# 세미툰 라이프 (가제) — 게임 기획 초안

세미툰 FAB와는 별개의 두 번째 게임입니다. 아직 기획 단계라 코드는 없습니다.

## 컨셉
- 랜덤으로 태어나 1살부터 선택을 이어 가며 한 사람의 삶을 사는 인생 시뮬레이션 (BitLife류).
- **누구로 태어나든 인생 어딘가에서 한 번은 반도체와 만난다.** 엔지니어뿐 아니라 보안게이트 요원, 구내식당 조리사, 용접공, 배관공, 팹 건설 현장까지.
- 현업에게는 공감, 일반인에게는 "반도체 산업이 이렇게 넓구나".
- 플랫폼: 웹 → 반응 좋으면 모바일. 기술 규칙은 저장소 AGENTS.md와 같음 (빌드 없음, 순수 HTML/CSS/JS).

## 시간
- 1년 = 1분 (기본). 배속 가능.
- 해마다 선택지 이벤트가 뜨고, 고르지 않으면 기본값으로 흘러감.

## 캐릭터 만들기
1. **직접 고르기**: 이름, 태어난 해
2. **주사위**: 아래 항목 전부
3. **다시 굴리기 3번**. 굴린 결과는 후보로 남고, 처음 결과까지 **4개 중 하나를 고름** (다시 굴려서 나빠져도 억울하지 않게)

| 구분 | 항목 |
|---|---|
| 출생 | 성별, 지역 (서울, 이천, 화성, 평택, 용인, 청주, 구미, 농촌 등) |
| 가정 | 아버지 직업, 어머니 직업, 경제력, 화목도, 형제 수 |
| 능력치 (0~100) | 체력, 지능, 손재주, 사교성, 멘탈, 외모 |
| 숨은 재능 | 처음엔 안 보이고 살면서 발견 (예: 15살 "설비 고치는 감각") |

- 손재주는 기능직(용접·배관·설비), 멘탈은 교대근무·야근 버티기에 쓰임. **지능이 낮다고 실패한 인생이 아니라 다른 길이 열리게.**
- 태어난 해에 맞는 분포: 1940년대생은 농촌 출생·농업 부모가 많고, 1980년대생부터 "아버지가 반도체 1세대 엔지니어"가 나올 수 있음.
- 반도체 공장 근처에서 태어나면 반도체와 만날 확률이 올라감.

## 태어난 해와 업계 역사
- 국적 기본값은 한국. **1940~2026년생** 중 선택. 1940년생은 25살에 고미반도체(1965) 1기, 34살에 한국반도체(1974) 창립 멤버가 될 수 있음.
- 나중에 외국 국적을 열면 1930년생부터 (페어차일드 1957 창업 세대).
- **2026년까지의 시황은 실제 역사를 따름** → `life/data/market_history.json` (연도별 세계 매출, 성장률, 분야별 시황 점수, 사건, 뉴스 헤드라인).
- 2027년부터는 랜덤 사이클 (호황·불황이 몇 년마다).
- 시황 점수는 채용 확률, 연봉·성과급, 구조조정 확률에 반영. 예: 1997년 졸업이면 취업난, 2018년 메모리 재직이면 성과급 대박.

## 직업
- **직종 × 소속 × 고용형태** 조합. 예: 용접공 = 장비사 정규직 / 건설 협력사 일용직 / 팹 유지보수 파견직.
- 현장: 공정·설비·수율 엔지니어, 연구원, 오퍼레이터(교대)
- 주변: 보안게이트, 구내식당, 통근버스, 방진복 세탁, 팹 건설
- 생태계: 장비·소재 협력사, 반도체학과 교수, 반도체주 개미 투자자, 이천·평택 원룸 임대업
- 끝까지 반도체를 피해 간 인생도 마지막에 이어 주는 장치: 은퇴 후 경비원, 자녀가 엔지니어, 대학 시절 팹 건설 알바 등.

## 회사
- 분야마다 **경쟁사 3~4곳**: 메모리, 파운드리, 팹리스, 장비, 소재, 패키징·테스트, 팹 건설, 급식·시설·보안. 총 25~30곳으로 시작.
- 실제 회사 이름을 살짝 바꾼 패러디 이름 (예: 삼송전자).
- 회사마다 다른 특징: 연봉, 워라밸, 안정성, 지역, 성장성.
- **회사 운명은 매년 변함**: 업계 시황 + 회사별 운 (기술 경쟁 승패 누적) → 1위 등극, 인수, 파산.
- **판마다 어느 회사가 성공하고 망할지 랜덤.** 다시 할 이유가 되고, 특정 실제 회사를 늘 망하는 회사로 그리지 않게 됨.
- 협력사는 원청을 따라감: 원청이 망하면 그 회사 식당·보안 계약도 끝남.
- 내 삶에 닿는 장면: 경쟁사 스카우트 ("연봉 1.5배, 대신 지방 근무"), 성과급 대박, 구조조정, 우리 회사 피인수, 망한 회사 동료들의 이직.

## 되돌아보기
- 인생 연표 + **"내 인생의 반도체 순간"** 카드 + 업계 연표 ("2041년 하이닉수, 삼송 추월").
- 이미지로 공유 → 인스타 홍보.

## 콘텐츠 규모
- 결말을 손으로 1만 개 쓰지 않음. 직업 경로 × 가족 × 재산 × 건강 × 사건 조합으로 수만 가지 인생이 나오고, 되돌아보기는 기록에서 자동 생성.
- 손으로 쓰는 건 이벤트 문장. 출시 목표: 이벤트 300~500개, 업적·칭호 100~200개, 이후 계속 추가.
- 이벤트·회사·직업은 코드가 아닌 **데이터 파일**로. 초안은 Claude가 대량 작성, 현업 감각 검수는 오너.

## 주의할 점
- 실제 회사를 알아볼 수 있는 이름에 부정적 이벤트(산재, 비리 등)를 고정으로 붙이지 않기. 정식 출시 전 법률 확인 권장.
- 회사 내부 정보(공정 조건, 수율 수치 등)는 넣지 않기.
