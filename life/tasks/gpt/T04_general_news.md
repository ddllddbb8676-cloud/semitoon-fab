# T04 1940~2026 일반 뉴스·생활상 연표

## 목적
게임 화면 위쪽에 그 해 뉴스가 흘러갑니다. 반도체 뉴스는 이미 `life/data/market_history.json`에 있으니, 당신은 **반도체 밖 세상**(정치·사회·문화·스포츠·생활 물가)을 맡습니다. 1988년에 태어난 캐릭터가 "서울 올림픽 개막"을 보고, 2002년엔 "월드컵 4강"을 보는 식입니다.

## 읽을 파일
`life/tasks/gpt/README.md`, `life/data/market_history.json`(겹치지 않게, 형식 참고).

## 할 일
- 1940~2026년 **매년** 한국 중심 헤드라인 3~5개 (세계 사건은 한국에 크게 닿은 것만). 게임 뉴스 말투: 짧고 신문 제목처럼.
- 매년 **생활상 한 줄** (예: 1975 "연탄 갈기가 아침 일과예요", 1995 "삐삐 번호 8282가 '빨리빨리'예요").
- 가능한 해는 **생활 물가** 3개: 짜장면 한 그릇, 시내버스 요금, 라면 1봉지 (원). 모르면 `null`.
- 전쟁·참사·민주화운동 같은 무거운 사건은 사실만 담담하게. 정치적 평가는 넣지 않기.
- 확실하지 않은 사실은 넣지 않거나 `confidence: "low"`. 출처를 알면 `sources`에.

## 형식
```json
{ "_note": "...", "years": [ { "year": 1988, "headlines_ko": ["서울 올림픽 개막", "..."], "life_ko": "...", "prices_krw": { "jjajang": 1300, "bus": 140, "ramen": 100 }, "confidence": "medium", "sources": [] } ] }
```
(예시 숫자는 자리표시일 뿐이에요. 실제 값을 확인해서 넣어 주세요.)
