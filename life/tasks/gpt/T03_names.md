# T03 시대별 한국 이름 데이터

## 목적
플레이어 이름은 직접 짓지만, 부모·형제·친구·연인·자녀·동료·팀장님 이름은 게임이 지어야 합니다. 1940년생 친구가 "서연"이면 몰입이 깨지니 시대에 맞는 이름이 필요합니다.

## 읽을 파일
`life/tasks/gpt/README.md`, `life/docs/GAME_DESIGN.md`.

## 할 일
- **성씨**: 상위 30개와 대략 비율(가중치).
- **이름**: 출생 연대별(1910~2020년대, 10년 단위) 남·여 각 40개 이상과 가중치. 1910~30년대는 부모·조부모 세대용입니다. 통계청·대법원 이름 통계 등 알려진 경향을 따르고, 자료가 불확실한 연대는 `confidence: "low"`.
- **미래 이름**: 2030~2140년대 남·여 각 30개. 근거는 없으니 지금 경향(중성 이름, 한 글자·외래 느낌 증가 등)을 이어 붙인 가상 목록이라고 `_note`에 밝히기.
- **호칭**: 직장 호칭이 시대마다 바뀌는 것 (예: 미스김 → ○○씨 → ○○님, 프로·매니저 호칭 도입 등) 연대별 정리.

## 형식
```json
{
  "_note": "...",
  "surnames": [ { "name": "김", "weight": 21.5 } ],
  "given": { "1940": { "m": [ { "name": "영수", "weight": 5 } ], "f": [ ... ], "confidence": "medium" } },
  "workplace_titles": [ { "from": 1960, "to": 1990, "examples_ko": ["미스 김", "김 대리"], "note_ko": "" } ]
}
```
