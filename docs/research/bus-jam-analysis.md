## 2. 장르의 계보

이 장르는 몇 단계를 거쳐 진화했어요. 핵심 구성요소는 세 가지입니다 [자료: Costcenter].

- **아이템**: 플레이어가 직접 못 움직임. 같은 색 컨테이너에 들어감 (= 승객)
- **컨테이너**: 플레이어가 움직임. 같은 색 아이템을 정해진 수만큼 모아야 함 (= 차)
- **슬롯**: 덜 찬 컨테이너를 임시로 세워두는 곳 (= 주차칸)

| 게임 | 퍼블리셔 | 출시 | 누적 다운로드 | 누적 매출 | 특징 |
|---|---|---|---|---|---|
| Parking Jam 3D | Popcore | 2020.02 | 2.15억+ | $3.1M+ | 차 빼기 원조. 하이퍼캐주얼 |
| Block Jam 3D | Voodoo | 2022.04 | 1,300만+ | $30M+ | 격자 배치로 난이도 정밀 조절 |
| Bus Jam | Rollic | 2023.06 | 1,460만+ | $7M+ | 승객을 움직여 버스에 태움 |
| Park Match! | Supersonic | 2024.04 | 50만+ | $34만+ | 세 요소를 모두 갖춘 초기작, 다운로드당 매출 높음 |

출처: Costcenter 경쟁작 분석 (수치는 해당 자료의 추정치)

**[분석] 진화 방향**
1. Parking Jam: 차를 꺼내기만 함 (공간 퍼즐)
2. Bus Jam: 승객을 움직여 버스에 태움 (색 매칭)
3. **기준 화면 계열** (Bus Out, Bus Fever, Car Jam 등): 차를 꺼내서 승객을 태움. 공간 퍼즐 + 색 매칭이 합쳐진 최신형

2024년 하반기에 Bus Out, Bus Frenzy, Bus Escape, Bus Sort, Car Jam 등 후속작이 쏟아졌고 [자료: Costcenter], 그중 Bus Out은 출시 1년 만에 1,000만 다운로드를 넘겼어요 [자료: MWM]. 이미 레드오션이라 **테마와 메타 구조로 차별화**해야 한다는 뜻이에요.

## 3. 기준 화면 구조 분석 [관찰]

화면은 위아래 3층 + 부스터 바로 나뉩니다.

```
┌──────────────────────────────┐
│ ↻            HARD 레벨 35   ⏸ │  ← 재시작 / 난이도 표시 / 일시정지
│   ╭─ 승객 행렬 (곡선 도로) ─╮   │  ← ① 색깔별 승객 떼가 줄지어 대기
│   ╰────────────────────────╯   │
│ [VIP][ ][ ][ ][ ][+][+][+]     │  ← ② 주차칸: VIP 1 + 일반 4 + 잠긴 칸 3
├──────────────────────────────┤
│   곡선 도로 위 차들(화살표)       │  ← ③ 주차장: 길이 뚫린 차만 빠짐
│   검은 ? 차 / 회전 표시 차 / 버스 │
│   차단기(빨강·흰색 바)           │
├──────────────────────────────┤
│ [부스터2] [부스터4] [VIP2] [상점]│  ← ④ 부스터 3종 + 상점
└──────────────────────────────┘
```

### ① 승객 행렬
- 같은 색 승객이 덩어리로 뭉쳐서 긴 곡선 도로를 따라 줄 서 있음
- 덩어리 크기가 제각각 → 어떤 색 차를 먼저 꺼낼지 계획하게 만듦
- 행렬 전체가 화면 위쪽을 가득 채워서 "이걸 언제 다 보내나" 하는 압박과 동시에, 줄어들 때 진척이 한눈에 보임

### ② 주차칸
- 일반칸 4개 + **VIP칸 1개**(노란색, 별도 규칙) + **잠긴 칸 3개**(점선 + 표시)
- 잠긴 칸은 아이템이나 결제로 여는 구조로 보임 → 이 자체가 과금 지점
- 칸이 하나씩 찰 때마다 위기감이 커지는 "체력 바" 역할

### ③ 주차장
- 차마다 진행 방향 화살표가 있고, 그 방향 길이 비어야 빠져나감
- **소형차·밴·버스** 크기가 섞여 있음. 크기가 클수록 태우는 승객이 많고 차지하는 공간도 큼 [관찰 + 자료: Bus Fever 설명의 버스·택시·밴]
- 일부 차는 **곡선 도로 위**에 줄지어 있어 앞차가 빠져야 뒤차가 움직임
- **검은 "?" 차**: 색이 가려진 미스터리 차. 꺼내기 전까지 무슨 색인지 모름
- **회전 아이콘(⟳)이 붙은 차**: 방향이 바뀌거나 돌아가는 기믹으로 보임
- **차단기(빨강·흰 줄무늬 바)**: 특정 조건 전까지 길을 막는 장애물

### ④ 부스터 바
- 부스터 3종 + 상점 버튼. 각 부스터 위에 보유 개수(2, 4, 2) 표시
  - 첫째: 버스·승객 그림. 승객 행렬 섞기 또는 승객 우선 태우기 계열 [분석]
  - 둘째: 회전 화살표. 차 방향 돌리기 또는 섞기 계열 [분석]
  - 셋째: VIP. 막힌 차 하나를 바로 VIP칸으로 빼기 [분석]
- 동종 게임에서도 VIP 슬롯, 헬리콥터(차 집어서 옮기기), 셔플이 대표 부스터로 소개됨 [자료: MWM의 Bus Out 설명]
- 상점 버튼이 부스터와 같은 줄에 있음 → 막히는 순간 손이 바로 상점으로 가게 하는 배치

## 4. 코어 규칙 (동작 흐름)

```
[차 탭]
  └─ 화살표 방향 길이 비었나?
       ├─ 아니오 → 차가 흔들리고 제자리 (실패 피드백, 손해 없음)
       └─ 예 → 차가 도로를 따라 빠져나가 빈 주차칸으로 이동
                 └─ 맨 앞 승객 색 == 그 차 색?
                      ├─ 예 → 승객이 줄줄이 탑승
                      │        └─ 정원 다 찼나? → 예: 출발, 칸이 빔 (+보상 연출)
                      └─ 아니오 → 그 칸에서 대기
[매 탑승 후] 맨 앞 승객 색이 바뀌면, 주차칸에 그 색 차가 있는지 다시 검사
[승객 0명] → 클리어
[주차칸 만석 + 맞는 차 없음] → 실패 → 이어하기 제안
```

**[분석] 규칙의 핵심 포인트**
- **꺼내기는 되돌릴 수 없다**: 한 번 꺼낸 차는 다시 주차장으로 못 돌아감. 그래서 모든 탭이 "결정"이 됨
- **승객은 순서대로만 탄다**: 맨 앞 덩어리 색이 정해져 있어서, 뒤에 올 색을 미리 읽고 차를 준비해야 함
- **차 크기와 승객 덩어리 크기가 안 맞으면** 차가 덜 찬 채로 칸을 오래 차지함 → 이게 실패의 주원인
- **막힌 차를 탭해도 벌칙이 없음**: 탐색은 자유, 결정만 무거움. 초보도 겁 없이 눌러볼 수 있게 한 장치

## 6. 재미 요소 분석 [분석]

### 6-1. 손맛 (감각 보상)
- 탭 → 차가 쭉 빠지는 움직임 → 승객이 줄줄이 타는 애니메이션까지, **한 번의 탭에 보상 연출이 2~3단계** 이어짐
- 3D 그래픽과 색 매칭 ASMR을 앞세운 게임들이 많음 [자료: Bus Fever 설명]
- 꽉 막힌 화면이 점점 비워지는 시각적 해소감

### 6-2. 긴장과 해소의 반복
- 주차칸이 하나씩 차오를 때마다 긴장 상승 → 버스가 출발해 칸이 비면 해소
- 한 판 안에서 이 파도가 여러 번 반복돼서 지루할 틈이 없음
- 실패가 대부분 **"한 칸만 더 있었으면"** 하는 아슬아슬한 상황 → 이어하기 결제를 부르는 감정 상태

### 6-3. 쉬운 진입, 깊은 계획
- 규칙 설명이 필요 없음 (색 맞추기 + 길 뚫기)
- 하지만 잘하려면 승객 순서 읽기, 차 크기 맞추기, 꺼낼 순서 짜기까지 계획이 필요
- 퍼즐 결정에 감정적으로 몰입할수록 리텐션이 높아진다는 분석과 맞닿음 [자료: Supersonic]

### 6-4. 짧은 세션과 "한 판만 더"
- 한 판 1~3분, 실패해도 바로 재시작
- 레벨 숫자가 계속 올라가는 단순한 진척감

### 6-5. 난이도 톱니 곡선
- 쉬운 판 몇 개 → HARD 판 → 다시 쉬운 판의 톱니 모양
- 쉬운 판에서 자신감을 쌓고, HARD 판에서 부스터를 쓰게 만들고, 깨면 큰 성취감
- 고정된 하드 레벨이 추가 이동·부스터가 필요해지는 수익화 지점이라는 업계 분석과 일치 [자료: Supersonic]

## 7. 과금 구조 분석

### 7-1. 재화 구조 [자료 + 분석]
| 재화 | 얻는 방법 | 쓰는 곳 |
|---|---|---|
| 하트(목숨) | 시간 충전, 구매 | 실패할 때 하나 소모. 다 떨어지면 기다리거나 구매 |
| 코인 | 클리어 보상, 구매 | 이어하기, 부스터 구매, 칸 해금 |
| 부스터 | 보상, 번들, 코인 구매 | 막힌 판 돌파 |

장르 전형은 일정 시간(예: 약 25분)마다 하트를 주고 코인으로 보충하게 하는 방식이에요 [자료: Supersonic].

### 7-2. 실제 인앱 상품 비교 [자료: App Store]

| 상품 유형 | Bus Jam (Rollic) | Bus Fever: Color Parking Jam | Bus Fever-Car Jam Escape |
|---|---|---|---|
| 코인 | $1.99 / $7.99 | 스타터 코인 $1.99 | $1.99 / $7.99 / $14.99 |
| 입문 번들 | $2.99, $4.99 | $2.99 | $1.99 |
| 광고 제거 | $3.99 | $9.99 | $6.99 패스 / $9.99 번들 |
| 이어하기 | (번들에 포함) | Revive Bundle $1.99 | - |
| 하트 | 무제한 하트+코인 $9.99 | 1시간 하트 $0.99 | - |
| 기간 한정 | - | Flash Sale $4.99, 시즌 번들 $9.99 | 3일 VIP 패스 $7.99 |
| 대형 번들 | $9.99 ~ $19.99 | $9.99 ~ $14.99 | 부스터 팩 $9.99 |

**[분석] 공통 패턴**
1. **입문 번들 $1.99~4.99**: 첫 결제 문턱을 낮춤. 가장 중요한 상품
2. **광고 제거**: 광고에 지친 유저를 결제자로 바꿈
3. **이어하기(Revive)**: 실패 직전 감정이 가장 높을 때 판매
4. **시간제 하트(1시간 무제한)**: 몰입한 세션을 끊기지 않게
5. **기간 한정·시즌 번들**: 긴급성으로 구매 유도
6. **단기 VIP 패스(3일)**: 구독형으로 넘어가는 다리

### 7-3. 광고 [자료 + 분석]
- **리워드 광고**: 실패 후 이어하기, 코인 보충의 핵심 수단 [자료: Supersonic]
- **전면 광고**: 레벨 사이에 노출. 장르에서 가장 큰 불만 요인 [자료: Bus Jam 리뷰, Bus Frenzy 리뷰 분석]
- 광고 제거 상품과 짝을 이루는 구조: 광고가 불편할수록 광고 제거가 팔림. 다만 과하면 평점과 리텐션이 무너짐

### 7-4. 과금 압력 지점 정리 [분석]
| 순간 | 플레이어 감정 | 판매하는 것 |
|---|---|---|
| 주차칸 하나 남음 | "망할 것 같다" | 부스터, 칸 해금 |
| 실패 직후 | "아깝다, 한 칸만 더" | 이어하기 (코인 / 광고 / 결제) |
| 하트 0개 | "더 하고 싶은데" | 하트 충전, 시간제 무제한 |
| HARD 레벨 진입 | "어렵겠다" | 시작 전 부스터 |
| 레벨 사이 광고 | "귀찮다" | 광고 제거 |
| 첫 며칠 | "괜찮네" | 입문 번들 |

## 8. 플레이어 불만과 리스크 [자료]

| 불만 | 출처 | 우리가 피할 방법 [분석] |
|---|---|---|
| 특정 하드 레벨은 유료 아이템 없이 사실상 불가능 | Bus Jam 리뷰 | 모든 레벨을 무과금으로 깰 수 있게 검증. FAB에서 부스터를 꾸준히 생산 |
| 클리어 보상(코인 10개 수준)에 비해 아이템이 너무 비쌈 | Bus Jam 리뷰 | 보상과 가격 비율을 시뮬레이션으로 맞춤 |
| 레벨마다 광고, 닫기 버튼이 불편함 | Bus Jam, Bus Frenzy | 전면 광고 최소화, 리워드 광고 위주 |
| HARD 표시가 실제 난이도와 다름 | Bus Jam 리뷰 | 레벨별 클리어율 데이터로 표시 보정 |
| 이벤트가 드묾 | Bus Jam 리뷰 | 월드·시즌 이벤트를 일정하게 |
| 승객 수가 안 맞는 버그로 진행 불가 | Bus Jam 리뷰 | 레벨 자동 검증 도구 (풀 수 있는지 컴퓨터가 확인) |
| 업데이트 후 멈춤·충돌 | Bus Frenzy 리뷰 분석 | 출시 전 기기 테스트 |

장르 평점은 대체로 4점대 중후반으로 높지만(Bus Jam 4.6, Bus Out 4.5), 불만은 거의 다 **과금과 광고**에 몰려 있어요. 퍼즐 자체의 재미는 검증됐고, 수익화를 얼마나 덜 거슬리게 하느냐가 승부처예요.

## 9. 「칩나라 FOUP 잼」에 주는 시사점 [분석]

### 9-1. 그대로 가져올 것
- 3층 구조 (행렬 → 칸 → 주차장)와 "꺼내면 되돌릴 수 없음" 규칙
- 크기 3종, 미스터리, 회전, 차단기 기믹 → 칩나라식으로 변환
- 일반칸 4 + 특별칸 1 + 잠긴 칸 구조
- 난이도 톱니 곡선과 HARD 표시
- 막힌 차를 탭해도 벌칙 없음

### 9-2. 대응표

| 원작 | 칩나라 FOUP 잼 |
|---|---|
| 승객 행렬 | 칩 꼬마들이 OHT 레일 위에 줄 섬 |
| 주차칸 4 + VIP 1 + 잠긴 칸 | 로드포트 4 + 핫Lot 포트 1 + 잠긴 포트 |
| 소형차 / 밴 / 버스 | 소형 FOUP / FOUP / 대형 카트 |
| 미스터리 검은 차 | 노이즈 안개 FOUP |
| 회전 차 | 에치 월드의 플라즈마 회전 FOUP |
| 차단기 | 장비 PM 중 바리케이드 (몇 턴 뒤 열림) |
| 부스터 3종 | 친구 능력 부스터 (클린 워터 샤워, 에치 플라즈마, 포토 플래시 등) |
| 상점 | 칩 크리스탈 상점 |

### 9-3. 차별화 포인트 (원작에 없는 것)
1. **메타 루프**: 원작은 레벨 숫자만 올라감. 우리는 퍼즐 → FAB 성장 → 부스터 생산 → 퍼즐의 순환 구조가 있어서 "계속 돌아올 이유"가 더 강함
2. **무과금 돌파 경로**: 원작 최대 불만인 과금 벽을, FAB이 만든 부스터로 해소. "돈 대신 시간과 전략으로도 깰 수 있다"를 내세울 수 있음
3. **세계관**: 8개 월드 = 8대공정, 월드마다 새 친구와 새 기믹. 애니메이션 IP와 서로 홍보
4. **교육 가치**: 아이들이 공정 순서와 이름을 자연스럽게 익힘. 부모에게 "보여줘도 되는 게임"이 됨

### 9-4. 아이도 하는 게임이라서 꼭 지킬 것
- 전면 광고는 최소화하고 리워드 광고는 보호자가 끌 수 있게
- 결제 전 확인 단계, 보호자 잠금
- 확률형 뽑기 없음
- 실패 화면에서 과한 압박 문구 쓰지 않기 ("지금 안 사면…" 류 금지)

### 9-5. 다음에 정할 것
- 레벨 1~30의 기믹 등장 순서와 난이도 곡선
- 크기 3종의 정원 (원작처럼 4 / 6 / 10명으로 갈지)
- 하트 충전 시간, 클리어 보상, 아이템 가격 (FAB 생산량과 함께 시뮬레이션)
- 레벨 자동 검증 도구 (각 레벨이 풀리는지 컴퓨터가 확인)
