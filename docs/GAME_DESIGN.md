# 세미툰 FAB — 게임 기획

## 컨셉
- 겉모습은 둥글둥글 귀엽게, 내용은 진짜 FAB.
- 장르: 방치형(인크리멘털) 키우기. 한 판 1~2분, 노드 전환은 며칠 단위.
- 타깃: 성인, 특히 반도체 현업 엔지니어. 세미툰 인스타 팔로워가 1차 유저.
- 플랫폼: 웹 프로토타입 → 반응 좋으면 모바일 앱.

## 코어 루프
웨이퍼 투입 → 8공정 라인을 흐름 → Lot 완성 + 수율 룰렛 → 돈 → 병목 증설 / 다음 공정 오픈 → 8공정 완성 → 노드 전환(리셋 + 기술 포인트) → 반복

## 시스템 (v0.1 구현됨)
| 시스템 | 내용 |
|---|---|
| 8공정 라인 | 세정→포토→식각→확산→이온주입→증착→금속배선→CMP. 라인 속도 = 가장 느린 공정(병목) |
| Lot 가치 | 열린 공정 가치의 합. 8공정 전부 열면 ×3 (완성 칩) |
| 수율 룰렛 | Lot마다 수율 랜덤(평균 86%). 1% 골든 Lot(99.9%, ×10), 2% 스크랩 |
| 수동 투입 | 탭 한 번 = Lot 하나. 초반 가속용 |
| 레벨 마일스톤 | Lv.10/25/50/100/200에서 속도 ×2 |
| 돌발 이벤트 | 장비 다운(라인 정지, 5번 탭해서 리셋), 파티클 폭주(수율 -25%p), 고객사 긴급 오더(60초 안에 목표 Lot) |
| 노드 전환 | 2D NAND → 3D 24단 → … → 400단+. 8공정 완성 + 누적 매출 조건. 돈·설비 초기화, 기술 포인트(매출 +5%/점) 획득. 노드마다 칩값·설비값 ×3 |
| 오프라인 수익 | 자리 비운 시간(최대 8시간)의 50% |
| 칭호 | 현업 공감 칭호 10종 |
| 저장 | 브라우저 localStorage, 10초마다 자동 |

## 밸런스 목표 (tools/sim.mjs 기준)
- 8공정 완성: 약 30분
- 첫 노드 전환: 약 40분
- 이후 노드: 20분~수 시간으로 점점 길어짐
