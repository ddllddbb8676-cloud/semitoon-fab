# 칩나라 FOUP 잼 — 모바일 플레이 테스트

[휴대폰에서 플레이](https://chipnara-foup-jam.ddllddbb8676.chatgpt.site)

사용자가 승인한 새 퍼즐 구상을 검증하는 독립 프로토타입입니다. 기존 FAB 방치형 게임과 파일·저장 상태를 공유하지 않습니다. 플레이 사이트는 오너 전용이며 같은 ChatGPT 계정으로 로그인해 열 수 있습니다.

## 게임 규칙

- 화살표 방향 끝까지 길이 열린 OHT만 탭해서 꺼낼 수 있습니다.
- 순환 레일에는 최대 4대가 들어갑니다. 같은 색 웨이퍼를 25장 모아야 공정으로 출발합니다.
- 웨이퍼는 입고 구역과 각 장비 옆에서 기다립니다. 공정 후 다음 목적지 색으로 바뀝니다.
- 수송을 마친 OHT는 퇴장합니다. 마지막 공정을 마친 웨이퍼는 출고됩니다.
- 모든 자동 탑승·배송·공정이 끝난 뒤 진행할 수 없으면 라인이 멈춥니다.
- 한 수 되돌리기와 해법 기반 힌트로 다른 순서를 시험할 수 있습니다. 시간 제한은 없습니다.

3판 구성: 50장/2공정, 75장/3공정, 100장/3공정. 모든 FOUP은 25장입니다. 그림은 게임 구조 확인을 위한 CSS 장비와 기호입니다.

## 실행과 확인

저장소 루트에서 `python -m http.server 8000` 실행 후 `http://localhost:8000/prototypes/foup-jam/`를 엽니다. `?level=3`으로 특정 판을 바로 열 수 있습니다.

`node --test prototypes/foup-jam/engine.test.mjs`

테스트는 실제 길막힘, 4칸 정체, 공정 연쇄, 모든 중간 프레임의 웨이퍼 보존, 되돌리기, 3판의 완주 가능성과 힌트의 유효성을 확인합니다. 라이브러리·설치·빌드가 필요하지 않습니다.

## 파일

- `index.html`: 화면 구조와 도움말
- `style.css`: 모바일·라이트/다크 모드와 동작 연출
- `game.js`: 터치 조작, 화면 반영, 애니메이션, 되돌리기, 선택형 효과음
- `engine.js`: DOM 없는 순수 퍼즐 규칙과 해법 탐색
- `levels.js`: 수동 설계한 3개 판
- `engine.test.mjs`: 규칙과 해법 검증

Sites 배포에는 위 HTML/CSS/JS 5개 파일만 그대로 복사합니다. 사용자 진행 기록은 브라우저 안에만 저장됩니다.
