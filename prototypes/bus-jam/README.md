# 버스 잼 프로토타입 (10레벨)

원작 버스 잼 게임의 규칙을 최대한 그대로 옮긴 손맛 확인용 프로토타입입니다. 칩나라 FOUP 잼을 만들기 전에 규칙과 난이도 감을 잡는 용도예요.

**플레이:** (Pages 켜진 뒤) https://ddllddbb8676-cloud.github.io/semitoon-fab/prototypes/bus-jam/

## 규칙
- 주차장 8×9칸, 차 6대(레벨 1)~24대(레벨 10)
- 화살표 방향 길이 뚫린 차만 꺼낼 수 있어요. 꺼낸 차는 돌면서 주차칸으로 가요
- 손님들은 갈고리 모양 도로를 따라 3줄로 서 있다가, 맨 앞부터 걸어가서 탑승
- 맨 앞 손님부터 같은 색 차에 탑승. 가득 차면 출발
- 주차칸(일반 4칸)이 꽉 찼는데 맨 앞 손님 색 차가 없으면 실패
- 차 크기: 소형 4명 / 밴 6명 / 버스 10명
- 검은 ? 차는 꺼내야 색이 보여요 (레벨 4부터)
- 차단기: 숫자만큼 차가 빠져나가면 열려요 (레벨 6부터)
- VIP 칸: VIP 빼기 부스터로만 사용. 잠긴 칸 3개는 코인·광고로 이번 판만 열기

## 부스터
- 승객 정렬: 주차칸에 있는 색 손님을 줄 앞으로
- 차 섞기: 주차장에 남은 차들 색을 같은 크기끼리 섞기
- VIP 빼기: 막혀 있어도 아무 차나 바로 VIP 칸으로

## 과금 흐름 재현 (실제 결제 없음)
하트 5개(다시 하기·포기 시 -1), 코인(클리어 +20, HARD +40), 실패 시 칸 +1 이어하기, 잠긴 칸 열기, 부스터 상점.

## 파일
| 파일 | 내용 |
|---|---|
| `core.js` | 규칙 (길 막힘 판정, 탑승, 자동 풀이기, 난이도 측정용 플레이어) |
| `game.js` | 화면과 조작 |
| `app.src.html` | 화면 뼈대와 스타일 |
| `levels.json` | 생성된 10레벨 (정답 순서 포함) |
| `index.html` | 빌드 결과 (한 파일) |

## 레벨 다시 만들기
```
node tools/bus-jam/gen.mjs     # 생성 + 풀이 검증 + 난이도 측정
node tools/bus-jam/build.mjs   # index.html 빌드
```
모든 레벨은 부스터 없이 일반 4칸으로 풀리는 것을 풀이기로 확인했습니다. HARD(5, 10)는 3칸으로는 안 풀리는 판만 골랐습니다.
